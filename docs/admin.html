Hüquq faktları

Faktları bir yerdə yazın, hər telefon özü götürsün.

Burada əlavə etdiyiniz hər fakt dərc olunduqdan sonra istifadəçilərin widget-lərində təsadüfi sırada görünür.

Admin girişi

Token necə yaradılır?
  1. GitHub-da Settings → Developer settings → Personal access tokens → Fine-grained tokens bölməsinə keçin.
  2. Repository access üçün yalnız bu repo-nu seçin.
  3. Permissions → Contents hüququnu Read and write edin.
  4. Yaranan tokeni buraya yapışdırın. Tokeni başqası ilə paylaşmayın.
Hüquq faktları

Kateqoriyalar

    Yeni fakt

    Fakt əvvəlcə siyahıya düşür. İstifadəçilər onu “Dərc et”dən sonra görür.

    Toplu əlavə et

    Yüzlərlə faktı bir dəfəyə siyahıya əlavə edin. Təkrar mətnlər keçilir.

    Sətir formatları: Fakt, Kateqoriya | Fakt, Kateqoriya | Fakt | Mənbə. CSV və JSON da yapışdıra bilərsiniz.
    CSV üçün sütun başlıqları: fakt, kateqoriya, mənbə. Excel-dən “CSV UTF-8” kimi saxlayın.
    Hələ heç nə yapışdırılmayıb.

    Widget ayarları

    Bu ayarlar bütün istifadəçilərin widget-lərinə şamil olunur.
