Hüquq faktı

Telefonun ekranında hər dəfə yeni bir hüquqi fakt.

Faktları mərkəz yazır, widget isə onları təsadüfi sırada göstərir. Bir dəfə quraşdırırsınız, yeni faktlar özü gəlir.

Quraşdırma

Bir telefon üçün təxminən bir dəqiqə çəkir.

  1. Scriptable tətbiqini yükləyin

    Widget-i bu pulsuz tətbiq göstərir. Artıq yüklənibsə, növbəti addıma keçin.

    App Store-da aç

  2. Widget kodunu kopyalayın

    Düyməyə basın. Kod telefonun buferinə köçürülür.

    Düymə işləmirsə

    Mətnin içinə toxunun, hamısını seçin və kopyalayın. Ya da skripti fayl kimi endirin və Paylaş menyusundan Scriptable-ə göndərin.

  3. Scriptable-də yapışdırın

    Scriptable-i açın, yeni skript yaradın, boş sahəyə uzun basıb Yapışdır seçin. Skripti “Hüquq faktı” adlandırıb Done basın.

    Scriptable-i aç

    Düymə yeni skript açmasa, Scriptable-də sağ üstdəki + işarəsinə basın.

  4. Widget-i ana ekrana qoyun

    Skripti Scriptable-də işə salmaq widget yaratmır, yalnız menyu açır. Widget ana ekrana ayrıca əlavə olunur:

    Ana ekran: boş yerə uzun basın, sol üstdəki + işarəsinə basın, Scriptable axtarıb ölçünü seçin (orta ölçü Fitness widget-i boyda olur) və Add Widget edin. Sonra ekrandakı boş widget-ə toxunun və Script sahəsində “Hüquq faktı”nı seçin.

    Kilid ekranı: kilid ekranına uzun basın, Customize deyin, saatın altındakı sahəyə toxunub Scriptable widget-ini əlavə edin.

Qısa suallar

Yeni fakt nə vaxt görünür?

iOS widget-lərin nə vaxt yenilənəcəyini özü müəyyən edir, ona görə hər açılışda yeni fakt zəmanət verilmir. Adətən bir neçə dəqiqədən bir dəyişir. Widget-ə toxunsanız, növbəti fakt tam ekranda açılır.

Yalnız bir sahənin faktlarını göstərmək olarmı?

Widget-ə uzun basın, Edit Widget deyin və Parameter sahəsinə kateqoriyanı yazın, məsələn Əmək hüququ. Rəngi də dəyişmək üçün: kateqoriya=Əmək hüququ;movzu=ocean.

İnternet olmayanda nə olur?

Widget son yüklənmiş faktları telefonda saxlayır və internet olmadan da işləyir.

Faktlar hüquqi məsləhətdirmi?

Xeyr. Faktlar ümumi məlumat üçündür. Konkret vəziyyətiniz üçün vəkilə müraciət edin.
